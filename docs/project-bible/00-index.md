## Evidence language

- **Confirmed fact:** Supplied in the approved project brief or explicitly decided by the project owner.
- **Research hypothesis:** A falsifiable explanation that has not yet been supported or rejected.
- **Operational assumption:** A temporary choice required to plan the work; it must be validated before it affects product decisions.
- **Illustrative example:** A non-evidentiary example used only to make a structure understandable.

## Lightweight review gates

1. Approve the Phase 1 research scope, questions, hypotheses, taxonomy, and source rules.
2. Review a small pilot corpus before scaling collection.
3. Approve the frozen corpus and behavioral synthesis before producing the PDD.
4. Approve the PDD and Opportunity Tree before authorizing a PRD.
5. Approve the PRD and UX before implementation.

Each gate should answer one decision question. Additional documents are created only when they improve evidence traceability or product reasoning.
