# Vision

- **Status:** Draft v1 — Awaiting human review
- **Owner:** Project Lead
- **Version:** 1.0
- **Last reviewed:** 2026-07-19
- **Purpose:** Define what the graduation project should demonstrate and the principles that constrain it.

## Confirmed direction

Build an evidence-backed product-discovery case for Zepto's category expansion goal, followed later by a Zepto-native MVP. The work must demonstrate behavioral research, disciplined product reasoning, appropriate AI use, measurable product design, and high-quality execution.

The project contains two separate products:

1. An internal research workflow that converts public discussions into traceable behavioral knowledge.
2. A Zepto-native MVP selected only after research, behavioral modeling, a Product Discovery Document, and opportunity prioritization.

## Intended outcome

A reviewer should be able to trace:

```text
public source → evidence item → behavioral concept → insight → behavior model
→ PDD → opportunity → product decision → metric → MVP
```

## Product principles

- Evidence before solution selection.
- Behavior before sentiment.
- Contradictions are actively sought, not hidden.
- AI output remains inspectable and reviewable.
- The MVP changes customer behavior rather than showcasing AI.
- The shopping experience remains native to Zepto's journey.
- Documentation stays small enough to maintain.

## Anti-goals

- Building a generic recommendation engine.
- Building a standalone AI dashboard presented as Zepto.
- Selecting a solution because it is visually impressive.
- Treating discounts or positive sentiment as sufficient insight.
- Claiming causality or representativeness from public discussions.
- Over-engineering infrastructure for a graduation project.

## Current evidence state

No user evidence has been collected yet. Statements about customer behavior remain research hypotheses or illustrative examples until linked to reviewed evidence.
